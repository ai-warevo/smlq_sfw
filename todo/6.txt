# Фаза 6: Импорт исторических чатов (Cold Storage + Embeddings)

**Цель:** Загрузить годы переписок из JSON-экспорта Telegram в БД с векторными представлениями.

**Стек:** C++20 (или Python-утилита), JSON парсер, Ollama Embeddings API, SQLite

---

## ТЗ

1. **Утилита `parser`:** отдельный бинарник или скрипт, запускается один раз.
   - Читает JSON-экспорт Telegram Desktop (`result.json`).
   - Склеивает подряд идущие сообщения одного автора в блоки (пауза < 60с = одна сессия, пауза > 30мин = разрыв сессии).
   - Фильтрует: игнорировать медиа-заглушки, системные сообщения, пересланные.

2. **Эмбеддинги:** для каждого блока `user_message` — POST-запрос к Ollama `/api/embeddings`, получить вектор.

3. **Таблица `historical_replies`:**
   - `id` (INTEGER PRIMARY KEY)
   - `user_message` (TEXT)
   - `my_reply` (TEXT)
   - `embedding` (BLOB — бинарный массив float)

4. **Прогресс:** выводить счётчик в консоль (обработано N пар).

## Верификация

- [ ] Парсер обрабатывает большой JSON без падений
- [ ] В БД записаны пары с векторами
- [ ] Ollama возвращает корректные эмбеддинги
