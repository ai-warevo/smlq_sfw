# Фаза 4: Интеграция с локальным LLM (Ollama / Qwen)

**Цель:** Заменить эхо-ответ на генерацию текста из локальной нейросети.

**Стек:** C++20, HTTP-клиент (cpprestsdk / httplib / libcurl), Docker

---

## ТЗ

1. **HTTP-клиент:** асинхронный POST-запрос к Ollama API (`/v1/chat/completions`).
2. **Формат запроса:**
   ```json
   {
     "model": "llama3.1:8b",
     "messages": [{"role": "user", "content": "<ТЕКСТ>"}],
     "stream": false
   }
   ```
3. **Системный промпт:** короткое правило стиля общения (разговорный, без заглавных, скобочки вместо смайлов).
4. **Обработка ошибок:** если LLM недоступен — логировать ошибку, не падать.
5. **Docker compose:** добавить сервис `ollama` с volume для моделей, лимитами ресурсов (CPU 6, RAM 16G).
6. **Ответ LLM** передаётся дальше в Presence Simulator (фаза 2).

## Верификация

- [ ] Бот отвечает осмысленно, а не эхом
- [ ] Стиль ответа соответствует системному промпту
- [ ] LLM недоступен → бот не падает
