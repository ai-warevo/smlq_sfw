# Архитектурные заметки (C++ TDLib-бот)

Этот файл — референс по правильной организации C++ бота на TDLib. Не ТЗ, а архитектурные принципы.

---

## 1. Авторизация и основной цикл

- Убрать консольное меню. Программа не ждёт человека.
- Бесконечный цикл `receive()` с таймаутом 1-10 сек.
- Авторизация (QR / 2FA) — только при первом запуске. При последующих TDLib подтягивает сессию из persistent volume.

## 2. Фильтрация `updateNewMessage`

- Игнорировать исходящие (`is_outgoing_`).
- Игнорировать старые сообщения (старше 10 сек от старта).
- Только `chatTypePrivate`.
- Извлекать текст, голосовые, стикеры.

## 3. Очередь задач и фоновая обработка

- Тяжёлые задачи (LLM, генерация) — в worker thread pool.
- TDLib `send()` потокобезопасен.
- Имитация человека: `sendChatAction` → пауза 1-3с → ответ.

## 4. Graceful Shutdown

- SIGTERM / SIGINT → флаг `is_running = false`.
- `ClientManager::close()` → ждать `authorizationStateClosed` → корректное сохранение БД.
