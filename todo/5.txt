# Фаза 5: SQLite — долгосрочная память (история диалогов)

**Цель:** Бот помнит контекст предыдущих разговоров с каждым пользователем.

**Стек:** C++20, SQLite (sqlite3.h), Docker volumes

---

## ТЗ

1. **Таблица `messages`:**
   - `id` (INTEGER PRIMARY KEY)
   - `user_id` (BIGINT)
   - `role` (TEXT: 'user' / 'assistant')
   - `content` (TEXT)
   - `timestamp` (DATETIME)

2. **Запись:** после flush буфера — записать входящее сообщение в БД. После ответа LLM — записать ответ в БД.

3. **Контекст перед запросом к LLM:** выбирать последние 10 сообщений пользователя из БД, передавать как историю в Chat API.

4. **Docker:** примонтировать volume `./db_data:/app/db_data` для сохранения БД при перезапуске.

5. **Асинхронность:** SQLite-запросы выполнять в фоновом потоке (`std::thread`), не блокируя event loop.

## Верификация

- [ ] Бот помнит, как зовут пользователя, если тот представился в прошлом сообщении
- [ ] История сохраняется после перезапуска контейнера
