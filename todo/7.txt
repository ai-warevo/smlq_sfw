# Фаза 7: Семантический роутер (векторный поиск на лету)

**Цель:** Бот ищет в своём прошлом похожие ситуации и использует их как примеры для ответа.

**Стек:** C++20, cosine similarity (чистый C++), Ollama Embeddings API, SQLite

---

## ТЗ

1. **Cosine Similarity:** функция на чистом C++ (без numpy), скалярное произведение / произведение нормалей.

2. **Поиск:**
   - При flush буфера: взять текущий текст → запросить эмбеддинг через Ollama `/api/embeddings`.
   - Загрузить все пары из `historical_replies`.
   - Рассчитать cosine similarity для каждой.
   - Вернуть ТОП-2-3 самых похожих пар (вопрос-ответ из прошлого).

3. **Интеграция:** найденные пары выводятся в консоль для отладки (на этом этапе). Если Ollama недоступен или база пуста — возвращать пустой список, не падать.

## Верификация

- [ ] Написание фразы из архива → в логах появляются соответствующие исторические пары
- [ ] Пустая база → бот работает без ошибок
- [ ] Ollama недоступен → бот работает без ошибок
