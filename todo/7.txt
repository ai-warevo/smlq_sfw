## Промт для AI-кодера (План на Фазу 7)

Привет! Мы переходим к Фазе 7: Интеграция семантического поиска на лету (Semantic Router Engine) в основного юзербота.
Наша цель — научить файл `main.py` находить в таблице `historical_replies` реплики из вашего прошлого, которые по смыслу максимально похожи на то, что собеседник написал прямо сейчас.

Вносим изменения ТОЛЬКО в файл `main.py`. Логику SQLite-логов из Фазы 5 и буфера из Фазы 3 ломать нельзя.

Требования к реализации:

1. Математическая функция сходства (Cosine Similarity):
   - Напиши на чистом Python функцию расчета косинусного сходства между двумя векторами (скалярное произведение векторов, деленное на произведение их длин). 
   - Не используй тяжелые библиотеки вроде numpy или scipy, так как мы пишем легковесный контейнер. Чистый Python через встроенный модуль `math` выполнит это мгновенно для массивов размера модели Llama.
   - Учти формат, в котором `parser.py` сохранил эмбеддинги в SQLite в Фазе 6 (если это BLOB, то декодируй его обратно в список float через `struct.unpack`, если это JSON-строка — через `json.loads`).

2. Логика семантического поиска (Функция `get_semantic_examples`):
   - Создай функцию, которая принимает на вход текущий склеенный текст входящего сообщения от собеседника.
   - Функция должна сделать POST-запрос к Ollama API на эндпоинт `/api/embeddings` для текущего входящего текста, чтобы получить вектор текущего запроса (массив float).
   - Затем функция должна забрать из SQLite из таблицы `historical_replies` ВСЕ сохраненные исторические строки и их векторы.
   - Для каждой исторической строки рассчитай косинусное сходство с текущим вектором.
   - Отсортируй результаты по убыванию сходства и верни ТОП-2 или ТОП-3 самые похожие пары (структура: `user_message` из прошлого и ваш реальный ответ `my_reply` на него).

3. Интеграция в основной рабочий цикл:
   - В точке кода, где 10-секундный буфер тишины закрылся, перед тем как сохранять входящий текст в логи (Фаза 5) и отправлять запрос в Ollama, вызови созданную функцию `get_semantic_examples(текущий_текст)`.
   - Полученный массив из ТОП-2 похожих пар (вопрос-ответ из прошлого) пока просто выводи в консоль через `print()` или стандартные логи контейнера для отладки.

Добавь обработку исключений (try-except). Если Ollama Embeddings API недоступна или база `historical_replies` пуста, функция должна возвращать пустой список, а бот — продолжать работу по стандартному сценарию без падения. Напиши чистый асинхронный код для main.py.
