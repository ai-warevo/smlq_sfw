# Фаза 8: Dynamic Prompt Constructor — сборка полного контекста

**Цель:** Объединить системный промпт, семантические примеры из прошлого и историю текущего диалога в один запрос к LLM.

**Стек:** C++20, HTTP-клиент, SQLite

---

## ТЗ

1. **Системный промпт:** короткий и жёсткий — правила стиля общения (разговорный, коротко, без смайлов, скобочки ).

2. **Сборка массива `messages` для LLM API:**
   - **А)** Системный промпт (role: system)
   - **Б)** Семантические примеры из прошлого (каждая пара = 2 сообщения: user + assistant)
   - **В)** История текущего диалога (последние 10 сообщений из БД, хронологически)

3. **Отправка и генерация:** собранный массив → POST к Ollama → ответ → дальше в Presence Simulator → отправка в Telegram.

4. **Запись ответа в БД** после успешной отправки.

## Верификация

- [ ] Ответ бота звучит как его собственный (стиль из прошлого + контекст текущего диалога)
- [ ] Семантические примеры влияют на манеру ответа
- [ ] Контекст не раздувается (ограничение: системный промпт + ТОП-2 пары + 10 последних сообщений)
